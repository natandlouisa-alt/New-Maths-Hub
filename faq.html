🔑 How to reset Sparx Password

You can set/reset your own password from home by:

  1. Clicking "Log in"
  2. Selecting St James
  3. Selecting "Forgot login details?" and then "Student"
  4. And then filling in the details below...
  5. You will then be able to choose your own password and it will remind you of your username.

Resourcing Our Maths Curriculum

📖 How to Resource Our Maths Curriculum Lessons (11-step guide)

Every lesson PowerPoint in the 26-27 Maths folder already exists but is blank: this guide shows how to fill it from the ERF resources in 11 steps.

Before you start

You need three things:

  • Access to the STJ Maths SharePoint site (the 26-27 Maths folder)
  • Access to the T Drive, at T:\Maths\01 - Staff\ERF\ERF Resources
  • The PowerPoint desktop app (not the browser version), so the lesson layouts appear under New Slide

The ERF file titles are not a perfect match to our scheme of work, but the resource you need will be in there.

Part 1: Open the blank lesson PowerPoint

  1. Go to 26-27 Maths on the STJ Maths SharePoint. It is the folder in the Documents library.
  2. Find your lesson. Open the lesson resources folder, then the unit folder (for example 09), then the cycle (for example Cycle 2), then the topic (for example 09 Rounding). Every PowerPoint for the unit is already there, but each one is blank.
  3. Open the PowerPoint in the app. Tick the file, click the three dots (or right-click), then choose Open > Open in app. Do not use "Open in browser": the lesson slide layouts only load in the desktop app.

Part 2: Copy in the ERF resources

  1. Go to the T Drive. Open T:\Maths\01 - Staff\ERF\ERF Resources.
  2. Open the ERF PowerPoint. The title will not be a perfect match to our scheme of work, but the resource you need will be in there.
  3. Select all and paste. In the ERF PowerPoint press Ctrl + A to select everything, then Ctrl + C to copy. Switch to the blank lesson PowerPoint and press Ctrl + V to paste.
  4. Do Now (optional). A Do Now slide is not necessary. Add one if you want a retrieval starter: use the Do Now layout from New Slide.

Part 3: Build the lesson slides

  1. Count the slides under each heading. In the ERF PowerPoint, count how many slides sit under each section heading (for example "Exploring Together"). In the blank lesson PowerPoint, click New Slide (Home tab, arrow underneath) and pick the matching layout from the office theme gallery. Insert that many slides for each heading.
  2. Copy and paste the content across. Copy each slide's content from the ERF PowerPoint and paste it into the matching slide you have just created.

Part 4: Task slides and saving

  1. Match the tasks to the layouts.
    TaskLayout to use
    Task 1Introduce
    Task 2Strengthen
    Task 3Deepen
    Each has an "Answers" version (for example Introduce Answers) in the same gallery.
  2. Save the PowerPoint. Press Ctrl + S. Because you opened it from SharePoint, it saves back to the same folder.
